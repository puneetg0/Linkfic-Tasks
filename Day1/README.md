## 1. Python Full Stack Developer

A Full Stack Developer works on both the frontend and backend of a web application. A Python Full Stack Developer commonly uses Python for backend development along with HTML, CSS, and JavaScript for the frontend.

## 2. Full Stack Architecture

Full Stack Architecture usually consists of:

* **Frontend** — User interface
* **Backend** — Business logic and APIs
* **Database** — Stores application data

Example:

`Frontend → API/Backend → Database`

## 3. Frontend vs Backend

* **Frontend** is the part users see and interact with.
* **Backend** handles application logic, APIs, authentication, and database operations.

## 4. Client-Server Architecture

The client, usually a web browser, sends requests to a server. The server processes the request and sends a response back to the client.

## 5. SDLC

SDLC stands for **Software Development Life Cycle**. It is the process used to develop and maintain software.

Main stages:

`Planning → Requirements → Design → Development → Testing → Deployment → Maintenance`

## 6. Startup Software Development

In a startup, developers usually work closely with product, design, and other teams. Tasks are planned, developed, tested, reviewed, and deployed in small iterations.

## 7. Version Control

Version control helps developers track changes in code and collaborate without losing previous versions.

## 8. Git

Git is a distributed version control system used to track code changes and manage different versions of a project.

Common commands:

```bash
git init
git status
git add
git commit
git pull
git push
```

## 9. GitHub

GitHub is a platform for hosting Git repositories. Developers use it to store code, collaborate, review changes, and manage projects.

## 11. Python Practice

### List vs Tuple

A **list** is mutable, meaning its contents can be changed. A **tuple** is immutable, meaning its contents cannot be changed after creation.

```python
my_list = [10, 20, 30]
my_tuple = (10, 20, 30)
```

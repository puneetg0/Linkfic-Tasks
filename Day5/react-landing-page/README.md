# React Landing Page

## Objective

Convert a traditional landing page into a React application using reusable components.

## Concepts Practiced

- React project setup with Vite
- JSX
- React Components
- Component-based Architecture
- Props and State concepts
- React Hooks basics
- Responsive CSS
- JavaScript array `map()`
- Git and GitHub workflow

## Component Structure

```text
App
├── Navbar
├── Hero
├── About
├── Services
├── Contact
└── Footer
```

## Run the Project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, usually:

```text
http://localhost:5173/
```

## Deliverable

A responsive React landing page divided into reusable components.
